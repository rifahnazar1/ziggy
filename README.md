# Ziggy's Birthday Page

A small static birthday site — messages from everyone, plus three riddles to crack.

**Live:** https://rifahnazar1.github.io/ziggy/

## Structure

- `index.html` — page markup
- `style.css` — styles and theme tokens
- `script.js` — starfield canvas, riddles, interactions
- `assets/` — images

## Running locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000
